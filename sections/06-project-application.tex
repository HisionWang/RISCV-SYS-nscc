\section{项目应用情况}
\subsection{落地应用}

项目处于方案设计阶段，首期以现有试验箱验证模型从主机准备、转换到板端推理及结果回传的完整过程，按“基础推理、静态视觉、感知接入”推进。具体演示场景待确定，尚无落地应用或企业试用记录。\cite{technicalreport}

首个算例采用\(\ModelImageHeight\times\ModelImageWidth\)灰度数字图像和\AIModel{}。主机准备来源清晰的权重、固定预处理、校准样本、独立测试集与逐层参考；板端仅执行推理，由\ModelOutputOperation{}输出类别，原始分数不作概率解释。算例用于贯通系统，行业模型另行适配。

原型面向算子开发、后端比较与执行验证，性能、开发工作量及部署成本随工程测试记录。移动数据中心的平台与接口待确认，通过结果输出适配层接入。

\par\textbf{\DrivingExtensionDirection{}展望。}基础推理与视觉接口稳定后，拟以\DrivingPilotTask{}为切入点，先通过图像序列回放开展预处理、模型量化及新增算子适配，再接入摄像头，输出\DrivingPilotOutput{}。后续比较不同光照、遮挡和输入频率下的识别效果与推理耗时，形成面向车载感知算法原型验证和教学演示的扩展示例。

\subsection{人机交互流程}

首期使用电脑端准备工具和串口交互完成操作。一次推理按以下顺序进行：

\begin{enumerate}
\item 电脑端选择模型与样本，检查形状、量化参数及后端支持情况，生成执行计划、权重和版本标识。
\item 操作者选择\RealTimeSystem{}或\LinuxDistribution{}启动镜像，重启进入相应环境，查看串口返回的初始化和就绪状态。
\item 通过串口加载程序或测试数据，提交带样本标识的任务，由运行时按计划执行并等待各步骤完成。
\item 回传样本标识、分类结果与诊断记录，在电脑端对照参考结果；参数不支持、初始化失败或执行异常时保留错误位置与状态。
\end{enumerate}

适配层统一张量输入和结果回传，摄像头及传感器驱动分别验证。
