# 图片与附件素材

本目录存放架构图源码与团队照片。`diagrams/` 中的软硬件架构图采用原生 TikZ，节点与图题调用 `config/diagrams.tex` 及硬件、软件配置宏；修改型号、功能与接口时同步检查图文关系。页面背景由 `styles/background.tex` 绘制，不依赖外部背景图片。

## 团队照片

team/ 中的 7 张成员照片和陈鹏老师照片均来自用户提供的“大创/汇总”目录，按原文件复制，未修改图像内容。照片路径及人物对应关系在 config/people.tex 维护。导师照片保存为 team/chen-peng.png，正文按原比例显示；照片文件缺失时自动显示预留框。
